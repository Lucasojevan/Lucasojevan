## Projeto em destaque

### [Finanças Open Local](https://github.com/Lucasojevan/financas-open-local)

Dashboard financeiro local com integração ao **Open Finance via Pluggy**. Reúne contas, cartões, faturas, transações e contas a pagar em uma interface responsiva.

- **Organização financeira:** saldo, fluxo mensal, gráficos e filtros por período, conta e categoria.
- **Integração:** conexão com instituições e sincronização de dados via API e webhooks.
- **Estrutura full stack:** frontend em Next.js, API em NestJS e persistência com Prisma e PostgreSQL.
- **Execução local:** ambiente com Docker Compose e autenticação para acesso à aplicação.

**Tecnologias:** TypeScript · React · Next.js · Node.js · NestJS · Prisma · PostgreSQL · Docker

[Explorar o código](https://github.com/Lucasojevan/financas-open-local) · [Conhecer o projeto](https://github.com/Lucasojevan/financas-open-local/blob/main/docs/PRODUCT.md) · [Ler a documentação](https://github.com/Lucasojevan/financas-open-local/blob/main/docs/README.md)
